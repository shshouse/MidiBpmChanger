# 🎵 MIDI BPM 修改器
一个简单的工具，用于批量导入 MIDI 文件并统一调整 BPM。
# 如何使用：
导入midi文件，程序会先检测出原bpm，输入你要转换的目标bpm，点击开始转换，转换后的文件会放在原文件同目录下。

# 🎵 MIDI BPM Changer
A simple tool for batch importing MIDI files and uniformly adjusting the BPM.
# How to use:
Import the MIDI file, the program will first detect the original BPM. Enter the target BPM you want to convert to, click "Start Conversion", and the converted file will be placed in the same directory as the original file.
